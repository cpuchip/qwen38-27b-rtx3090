2. EAGLE-3.1 exists: vLLM blog 2026-05-26 https://vllm.ai/blog/2026-05-26-eagle-3-1. Adds fc_norm (RMSNorm per aux hidden state before FC) and norm_output (post-norm state fed to next step), plus target_hidden_size / num_aux_hidden_states; still method "eagle3" in vLLM. No own paper; cites attention-drift paper arXiv 2605.09992 (2026-05-11). vLLM PR #42764 merged 2026-05-19; TorchSpec PR lightseekorg/TorchSpec#97. Checkpoints: lightseekorg/kimi-k2.6-eagle3.1-mla, SyzygyResearch/DeepSeek-V4-Flash-EAGLE3.1, lightseekorg/kimi-k2.7-coder-eagle3.1-mla, amd/MiniMax-M3-EAGLE3.1. None Qwen. SpecForge ships configs/qwen3-30B-A3B-eagle3.1.json.

3. SpecForge (github.com/sgl-project/SpecForge, docs at sgl-project.github.io/SpecForge, paper arXiv 2603.18567 2026-03-19) trains EAGLE3, P-EAGLE, EAGLE3.1, DFlash, DFlash2, Domino, DSpark. Docs state NO GPU count or hours anywhere. Paper: 8x H200, Open-PerfectBlend 1.4M convs, 2 epochs, throughput only. Real costs from SpecForge-trained cards: taobao-mnn/Qwen3-4B-Instruct-2507-Eagle3 = 8x MI308X, 56 h, 448 GPU-h; Qwen3-VL-8B = 74 h, 592 GPU-h. DEER paper arXiv 2512.15176 Table 8: EAGLE-3 696 GPU-h (Qwen3-8B), 1440 GPU-h (Qwen3-14B) on 8x A100. No Qwen3.8 config/yaml (47 configs); hybrid GDN targets are supported (qwen3-next-80b, qwen3.5-35b-a3b eagle3; qwen3.6-27b dflash/dflash2/domino/dspark only, no 27B eagle3). Online training captures from a patched SGLang server, so any SGLang-servable target works; RadixArk's Qwen3.8-27B-DSpark card confirms SpecForge on this exact target.

4. vLLM: latest release v0.28.0 (2026-08-26); v0.29.0 does not exist as of 2026-09-05. Methods at 0.28 (verbatim Literal): ngram, medusa, mlp_speculator, draft_model, suffix, custom_class, eagle, eagle3, extract_hidden_states, mtp variants, dflash, ngram_gpu, dspark. ngram: prompt_lookup_max/min both default 5. suffix: method "suffix", requires pip install arctic-inference==0.1.1, defaults max_tree_depth 24, max_cached_requests 10000, max_spec_factor 1.0, min_token_prob 0.1, num_speculative_tokens defaults to 24, docs recommend 16-32 for code-editing/agentic loops/RL rollouts.
